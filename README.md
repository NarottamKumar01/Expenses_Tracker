# Expense Tracker

A simple Python-based Expense Tracker that helps users record, manage, and analyze their daily expenses.

## 📌 Project Overview

People spend money every day but often lose track of where their money goes. This project provides a simple command-line application for recording expenses and viewing spending information.

The project is built using Python and focuses on fundamental programming concepts such as **functions, lists, dictionaries, file handling, and JSON**.

## ✨ Features

* ➕ Add an expense
* 👀 View all expenses
* 🗑️ Delete an expense
* 📂 Categorize expenses
* 💰 Calculate total spending
* 📊 View category-wise spending
* 💾 Store expenses permanently using JSON
* 📈 Generate a spending pie chart using Matplotlib

## 🗂️ Expense Categories

The application supports categories such as:
